# V16.2 — рабочая папка SOLIDWORKS

BUILD_ID: MERGE_DRAWINGS_V16_2_WORKING_DIRECTORY_20261027

В журнале пользователя V16.1 прошла чтение исходного чертежа и создание копии,
затем остановилась по Boolean SetCurrentWorkingDirectory=False. Текущая папка
не записывалась; журнал не доказывает, что переключение действительно требовалось
или что папка после вызова была неверной. Причина False в SOLIDWORKS не установлена.

EnsureWorkingDirectory проверяет существование папки, сравнивает её с текущей,
пропускает ненужную установку и после вызова проверяет GetCurrentWorkingDirectory.
Результат API и пути пишутся в CWD CURRENT / CWD SET. Неверная папка приводит
к остановке даже при API=True. Настройка и восстановление используют один helper,
включая попытку восстановления при ошибке. Ошибка восстановления при аварийном
выходе не заменяет первоначальную ошибку. Для родительской папки используется
FSO.GetParentFolderName, корректный также для файлов в корне диска.

Исправление активации листов V16.1 сохранено. Сверка видов, моделей, родителей,
сохранение и повторное открытие результата не отключены.

Установка: полностью заменить прежний стандартный модуль текстом
MERGE_DRAWINGS_V16.txt (UTF-8) либо импортировать MergeDrawingsV16.bas (CP1251)
вместо прежнего модуля. Имена файлов сохранены; не оставлять два модуля.
Выполнить Debug → Compile, запустить main, проверить BUILD_ID в новом merge.log.

На Linux выполнены сборка, проверка эквивалентности BAS/TXT, ограничений строк,
продолжений и уникальности процедур; экспорт PDF совпадает с V16.1.
ZIP проверен на CRC. Компиляция VBA и запуск в SOLIDWORKS не выполнялись.
Остальные документы и отчёты checks относятся к предыдущим версиям,
не подтверждают нативную работоспособность V16.2. Старые check_release.py,
check_api.py и package_release.py требуют отсутствующего research-окружения.

Повторить запуск с теми же входными файлами. Ожидаемый итог исходного сценария:
SUCCESS, 9 листов и оба связанных разреза. Если снова FAILED, передать полный
новый merge.log с CWD SET/CURRENT, OPEN и CLONE. При настоящем отказе смены
