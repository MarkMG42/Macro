## Обновление

Заменить только стандартный модуль содержимым MERGE_DRAWINGS_V16_18.txt,
выполнить Debug → Compile, сохранить .swp и запустить main. Форму frmDrawingOrder
и FORM_CODE.txt не менять. Можно вместо вставки текста удалить предыдущий стандартный
модуль и импортировать MergeDrawingsV16_18.bas (Windows-1251). Не оставлять два main.

Для первой установки создать .swp, вставить стандартный модуль, добавить пустую
UserForm с (Name)=frmDrawingOrder и вставить FORM_CODE.txt в код формы. Контролы
создаются в VBA. В архиве исходники, не бинарный макрос .swp.

## Новый порядок работы

1. Создаётся один новый MERGED_<дата>_<время>.slddrw рядом с основным чертежом.
   Он и является рабочим документом объединения. Отдельного WORK_TARGET нет.
2. Начальное содержимое основного чертежа копируется побайтово в этот новый файл.
   Это сохраняет исходную нативную структуру без SaveAs исходника. Сам основной
   файл не редактируется и не перезаписывается. Для определения времени файлового
   копирования добавлены отдельные отметки начала/конца в журнал.
3. Основные листы перестраиваются один раз при подготовке результата. При добавлении
   источника перестраиваются только его новые листы. Проверка перед сохранением
   использует последний полный проверенный снимок; ещё одного принудительного
   прохода перестроения всего документа перед Save3 нет.
4. Выполняется один Save3 сразу в MERGED_….slddrw. Затем читается и проверяется
   открытый документ после Save3: виды, родители, геометрия, штампы, штриховки и
   компонентные заметки. Проверяются также код ссылки, привязки и непустой исходный текст.
5. Создаются verified_views.tsv и PDF. Результат остаётся открытым.

Убрана повторная CaptureDrawing основного чертежа сразу после уже проверенной
копии. RequireActive теперь не вызывает ActivateDoc3, если нужный документ уже активен.
Алгоритм копирования листов, восстановления разрезов, связанных заметок и источников
свойств от V16.17 не менялся. Скрытые служебные виды свойств сохранены; видимые виды
деталей на листах «Рамы» не заменяются видами сборки.

Для источников с родителем и разрезом/выносным видом на разных листах по-прежнему
нужна отдельная редактируемая копия: в ней временно собирается семейство видов.
Обычные источники открываются для чтения и переносятся прямо из исходного документа.

## Быстрый и строгий режим

По умолчанию в начале стандартного модуля:

```vb
Private Const VERIFY_AFTER_SAVE As Boolean = False
```

Автоматического закрытия/повторного открытия и второго Save3 в этом режиме нет.
SUCCESS означает, что Save3 и PDF вернули успех и проверки открытого документа
после Save3 прошли. **Успех проверки сохранённого файла после повторного открытия
в этом режиме не установлен.** STATUS.txt явно сообщает, что открытия не было.
При первом запуске нового варианта проверьте результат также после ручного открытия.

Чтобы включить прежнюю дополнительную проверку сохранённого документа, изменить
False на True, скомпилировать и сохранить .swp. Будут выполнены закрытие/открытие,
полное перестроение, сравнение и ещё один Save3. Этот режим медленнее.

## Файлы и остановка

MERGED_….slddrw и .pdf — рядом с ОСНОВНЫМ чертежом. В runs/<дата>_<время> остаются
merge.log, STATUS.txt, verified_views.tsv, временный PDF и SOURCE-копии, если они нужны.
Существующие файлы не перезаписываются. Автоматический поиск пропускает MERGED_….

MERGED создаётся в начале и до SUCCESS может содержать только часть результата.
При ошибке он остаётся открытым; выполняется попытка сохранить частичный результат
по тому же точно зарегистрированному пути. STATUS остаётся FAILED. Оригинальные
основной и исходные чертежи не сохраняются, путь к любому другому внешнему файлу
не допускается защитой RequireOwnedPath. При ошибке самого Save3 документ остаётся
открытым для ручного сохранения. Не считайте незавершённый MERGED готовым результатом.

## Проверки

Проверяются грамматика полного VBA, BAS/TXT, лимиты VBA, неизменность формы, кода
переноса видов/заметок, прежних архивов и ограничений записи. Сигнатуры API унаследованы
от проверенной V16.17; новые методы SOLIDWORKS не добавлялись. Архив проверяется
на целостность и соответствие исходникам. Нативная компиляция VBA и запуск SOLIDWORKS
в этой среде недоступны. Скорость и результат V16.18 ещё нужно проверить в SOLIDWORKS.
