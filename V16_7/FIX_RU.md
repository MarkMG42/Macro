# V16.7 — источник свойств листа

BUILD_ID: MERGE_DRAWINGS_V16_7_SHEET_PROPERTIES_20261027

Журнал V16.6 подтвердил ForceRebuild3=True с raw=1: предположение о COM Boolean
подтвердилось. Все 4 листа источника добавлены к основному, разрезы перенесены
обратно на предназначенный лист. VerifyStructure перед полной проверкой
AFTER source 1 завершилась без ошибки (включая родителей и модели видов).
Полная проверка остановилась на PropertyView листа Лист1(2). Сохранение итогового
документа, повторное открытие и PDF ещё не выполнялись.

CustomPropertyView задаёт, из какого вида лист берёт свойства модели (в том числе
для $PRPSHEET в штампе). Поэтому несовпадение нельзя игнорировать из-за хорошего
внешнего вида чертежа. Предыдущая версия задавала свойство ISheet без активации
соответствующего листа. Значения expected/actual в старом журнале отсутствуют;
точная причина несовпадения ещё не установлена.

V16.7 перед присваиванием активирует и проверяет каждый лист назначения,
очищает выбор и заново получает ISheet через GetCurrentSheet. Сопоставление
исходных имён видов с новыми именами сохранено. PROPERTY VIEW before/readback
показывают исходное, запрошенное и прочитанное значения. Окончательная сверка
по-прежнему выполняется после перестроения; несовпадение — ошибка с точными
expected/actual. Нет подмены ожидаемого значения фактическим и нет угадывания
другого вида. Все остальные проверки сохранены.

Установка: полностью заменить стандартный модуль содержимым
MERGE_DRAWINGS_V16.txt (UTF-8), либо импортировать MergeDrawingsV16.bas (CP1251)
вместо прежнего модуля. Не оставлять оба модуля. Debug → Compile, сохранить .swp,
запустить main и проверить новый BUILD_ID. Имена файлов оставлены прежними.
Использовать исходные сохранённые чертежи, не копии неудачного запуска.

Здесь: сборка BAS/TXT, эквивалентность кодировок, лимиты строк/продолжений,
уникальность процедур, аудит изменений (AppendDrawing и диагностика VerifyDrawing),
неизменность PDF-экспорта и проверка состава/SHA-256/CRC ZIP.
Компиляция VBA и нативное испытание в SOLIDWORKS здесь не выполнялись.
Остальные markdown/checks исторические и не доказывают проверку V16.7.
