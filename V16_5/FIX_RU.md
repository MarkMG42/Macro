# V16.5 — резервное перестроение чертежа

BUILD_ID: MERGE_DRAWINGS_V16_5_DRAWING_REBUILD_20261027

Журнал V16.4 подтверждает перенос обоих разрезов А-А/Б-Б с Лист1(2)(2) на
Лист1(2) в рабочей копии источника. После каждого переноса CaptureDrawing и
VerifyStructure завершились без ошибки. Затем ForceRebuild3(False) вернул False
на Лист1. До копирования целых листов в итоговый документ код ещё не дошёл.
По журналу нельзя установить, было ли повреждение или только отказ API.

Изменена только RebuildDrawing и BUILD_ID. ForceRebuild3 остаётся первым методом.
Если он возвращает False, вызывается обычное перестроение EditRebuild3 один раз.
Если оно также вернёт False, макрос остановится с именем документа, листа и обоими
результатами. Возвращаемые значения пишутся отдельно (REBUILD begin,
REBUILD ForceRebuild3, REBUILD EditRebuild3). Нет принятия False как успеха,
нет слепого повторения одной операции. После обхода восстановлен активный лист.
Остальные проверки геометрии, структуры, родителей, оформления, сохранения,
повторного открытия и PDF не изменены.

Контекст: xCAD отмечает ненадёжность Boolean ForceRebuild3 в отдельных случаях:
https://github.com/xarial/xcad/blob/master/src/SolidWorks/Documents/SwDocument.cs
Это основание попробовать другой штатный метод, а не доказательство причины
именно этого сбоя. Успешность резервного пути требует запуска у пользователя.

Установка: полностью заменить код стандартного модуля файлом
MERGE_DRAWINGS_V16.txt (UTF-8) либо импортировать MergeDrawingsV16.bas (CP1251)
вместо него. Не оставлять оба модуля. Выполнить Debug → Compile, сохранить .swp,
запустить main, проверить новый BUILD_ID. Имена файлов оставлены прежними.
Использовать исходные сохранённые чертежи, не рабочие копии неудачного запуска.

Здесь выполнены сборка, эквивалентность BAS/TXT, лимиты строк/продолжений,
уникальность процедур, проверка области изменения (только RebuildDrawing),
неизменность PDF-экспорта и целостность ZIP/SHA-256. Сигнатура EditRebuild3
сверена с метаданными SolidWorks.Interop.sldworks 32.1.0 (ABI SW 2024).
Компиляция VBA и выполнение COM/SOLIDWORKS здесь не выполнялись.
Другие документы/checks — исторические, не доказательство проверки V16.5;
старые исследовательские инструменты требуют отсутствующего research-окружения.

Для текущего комплекта ожидаются 5 листов, сохранённые родители обоих разрезов,
SUCCESS, итоговый чертёж и PDF. При новом сбое передать полный merge.log.
Если оба метода перестроения вернут False, отказ остаётся нерешённым: потребуется
диагностика ошибок перестроения и ссылок на модели в SOLIDWORKS; его нельзя
обойти удалением проверки и считать результат исправным.
