# V16.6 — обработка Boolean из COM

BUILD_ID: MERGE_DRAWINGS_V16_6_COM_BOOLEAN_20261027

Журнал V16.5 противоречит прежнему диагнозу: ForceRebuild3=True и EditRebuild3=True,
но выполнена ветка If Not forced, затем Require отклонил rebuilt. Текст FAILED
содержит False как константу из сообщения, это не фактические значения API.
Отказ перестроения по этому журналу не доказан. Предыдущая трактовка была неточной.

Вероятное объяснение: неканонический VARIANT_BOOL +1 вместо стандартного VBA True=-1.
В VBA Not — побитовая операция: Not 1=-2 (тоже ненулевое, то есть истинное).
Это объясняет одновременно вход в If Not forced и остановку в Require,
где было If Not condition. Подтверждение конкретного raw-значения требует нового
запуска; теперь в строках REBUILD записываются CStr и CLng ответа API.

Исправления:
- Require проверяет положительное условие: If condition Then Exit Sub, иначе ошибка.
  Ноль по-прежнему отклоняется, любое ненулевое значение принимается как истина.
- Ветка резервного перестроения проверяет forced = False, без побитового Not.
- Проверка несохранённого исходника: model.GetSaveFlag = False. Ранее Not над
  неканонической истиной мог ошибочно пропустить несохранённый документ.
- FlagValue нормализует Boolean-флаги на границе чтения из SW для снимков
  (проекция, видимость формата, масштаб родителя, блокировка, параметры разрезов)
  и сравнения/восстановления. Это исключает ложное различие истин +1 и -1.

Проверки видов, родителей, геометрии, аннотаций, сохранения/повторного открытия
остаются. Отказ обоих методов перестроения с фактическим нулём остаётся ошибкой.
Предыдущие исправления выбора/вставки сохранены. Полное объединение пока не доказано.

Установка: полностью заменить код стандартного модуля содержимым
MERGE_DRAWINGS_V16.txt (UTF-8), либо импортировать MergeDrawingsV16.bas (CP1251)
вместо прежнего модуля. Не оставлять два модуля. Debug → Compile, сохранить .swp,
запустить main. Имена файлов сохранены; проверять новый BUILD_ID.
Использовать исходные сохранённые чертежи, не рабочие копии прошлых запусков.

Здесь: сборка, эквивалентность BAS/TXT, лимиты строк и продолжений, уникальность
процедур, аудит области изменений, неизменность PDF-экспорта, контроль ZIP/SHA-256.
Числовая модель 16-битного Not для 0/+1/-1 проверена отдельно; это не исполнение
VBA. Компиляция VBA и запуск COM/SOLIDWORKS здесь не выполнялись.
Старые markdown/checks — исторические сведения, не проверка V16.6.
Исследовательские скрипты старой поставки требуют отсутствующего research.

Повторить запуск на том же комплекте. Ожидаются 5 листов, исходные родительские
связи обоих разрезов, SUCCESS, итоговый SLDDRW и PDF. При ошибке нужен полный
новый merge.log, особенно строки REBUILD с raw. Если обе строки покажут нулевой
результат, диагностировать собственно перестроение, а не обходить проверку.
