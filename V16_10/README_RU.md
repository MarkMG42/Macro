# V16.10 — возвращена сортировка перетаскиванием

BUILD_ID: MERGE_DRAWINGS_V16_10_RESTORED_SORT_20261027

Окно порядка восстановлено из V16.7 без изменений: перетаскивание, удаление строк,
добавление папки и подтверждение. GetOrderedSourceFiles, DragDropOrderDialog и
JsQuote в готовом модуле совпадают с V16.7, включая дополнительные изменения
сборщика (публикация файла результата после закрытия записи). Команды InputBox
из V16.9 больше не используются в этой версии. Окно снова запускается через
mshta.exe и использует локальные ActiveX-объекты, как в V16.7.

## Последняя ошибка объединения

V16.9 дошла до проверки PropertyView, но явное имя вида не применилось.
У ISheet.GetProperties2/SetProperties2 есть отдельный флаг
SameCustomPropAsSheetInDocProp (восьмой элемент/параметр). Он выбирает наследование
источника свойств из настроек документа. Предыдущие версии его не восстанавливали.

Теперь флаг читается из оригинала и сохраняется в снимке. Перед заданием источника
свойств он восстанавливается через SetProperties2 с прежними размерами, шаблоном,
проекцией и масштабом листа. В локальном режиме затем задаётся имя вида; в режиме
наследования сохраняется режим документа. Чтение флага после записи проверяется,
после перестроения и повторного открытия проверяются и флаг, и имя источника.
Диагностика PROPERTY MODE before/readback показывает результат. Исправление
требует нативного запуска; наличие нужного API и восемь параметров сверены
с SolidWorks.Interop.sldworks 32.1.0. Геометрия и связи по-прежнему проверяются.
Заполнение штампов, особенно в наследуемом режиме, нужно сравнить с исходниками.

## Установка

Полностью заменить стандартный модуль содержимым MERGE_DRAWINGS_V16_10.txt
(UTF-8) либо импортировать MergeDrawingsV16_10.bas (Windows-1251) вместо прежнего
модуля. Не оставлять разные версии вместе. Debug → Compile, сохранить .swp,
запустить main и проверить BUILD_ID. Использовать исходные сохранённые чертежи.
Для текущего комплекта ожидаются 5 листов, оба связанных разреза, SUCCESS,
сохранённые итоговые SLDDRW/PDF. При ошибке нужен полный merge.log.

## Проверки и ограничения

Проверены совпадение возвращённого интерфейса с V16.7, эквивалентность BAS/TXT,
пределы строк/продолжений, уникальность процедур, неизменность PDF-экспорта,
грамматика полного VBA-модуля независимым ANTLR-парсером и целостность архива.
Это не компиляция в редакторе VBA, не запуск SOLIDWORKS и не проверка Defender.
Результаты находятся в checks. Python tools/build_release.py пересобирает модуль;
tools/package_release.py проверяет и упаковывает поставку без внешних зависимостей.

История скачивания разобрана в DOWNLOAD_CHECK_RU.md; точный diff V16.7→V16.8
приложен отдельно. Причина прежней блокировки не установлена. Не отключать
Defender и не добавлять исключения ради запуска. Если блокировка повторится,
нужен видимый текст предупреждения браузера/Defender — журнал администратора
не является единственным источником этих сведений.
