# V16.22 — сохранение в основной чертёж

BUILD_ID: MERGE_DRAWINGS_V16_22_SAVE_MAIN_20261028

## Обновление

Заменить только стандартный модуль текстом MERGE_DRAWINGS_V16_22.txt,
выполнить Debug → Compile и сохранить .swp. Форму frmDrawingOrder не менять.
Альтернатива — удалить старый стандартный модуль и импортировать MergeDrawingsV16_22.bas
(Windows-1251). Не оставлять два main. При первой установке создать .swp со стандартным
модулем и пустой UserForm с (Name)=frmDrawingOrder; вставить FORM_CODE.txt в код формы.

## Сохранение

Выбранный ОСНОВНОЙ чертёж теперь редактируется и сохраняется по своему прежнему пути,
с прежним именем. Отдельный MERGED_….slddrw не создаётся. Исходники, добавляемые к
основному чертежу, по-прежнему не перезаписываются. Открытые файлы с несохранёнными
изменениями нужно сохранить до запуска; основной файл должен быть открыт для записи.

Перед открытием/перестроением основного документа его сохранённое содержимое
копируется в runs/<дата>_<время>/BACKUP_MAIN.slddrw. Если копирование не удалось,
изменение основного документа не начинается. Проверяются наличие и размер копии.
Это резервная копия для восстановления, не отдельный результат объединения.

После объединения и проверки выполняется Save3 основного документа. По умолчанию
VERIFY_AFTER_SAVE=False: после Save3 проверяется открытый документ без закрытия и
повторного открытия. True включает дополнительную медленную проверку после открытия.
PDF создаётся рядом: <имя основного>_MERGED_<дата>_<время>.pdf, чтобы не перезаписать
существующий PDF. Журнал, STATUS.txt и verified_views.tsv — в папке запуска.
Для межлистовых семейств разрезов всё ещё могут создаваться временные SOURCE-копии.

## Если произошла ошибка

Основной документ остаётся открытым. Автосохранение при FAILED отключено: частичный
результат дополнительно не записывается в исходный файл. Если ошибка возникла уже
после начала Save3 (например, при проверке после сохранения или экспорте PDF), файл
на диске мог измениться. Состояние FAILED не означает автоматический откат.

Чтобы вернуть исходное состояние, закрыть основной документ без сохранения,
затем скопировать BACKUP_MAIN.slddrw поверх основного файла по его прежнему пути.
Не заменять открытый в SOLIDWORKS файл. Простое открытие резервной копии из runs
может иначе разрешать относительные ссылки; восстанавливать нужно в исходную папку.

Повторный запуск на уже объединённом основном чертеже добавит выбранные листы ещё раз.
Для повторения прежнего объединения сначала восстановить резервную копию.

## Проверки и рабочая версия

Перенос разрезов и восстановление связанных заметок — без изменений из V16.21,
работу которой пользователь подтвердил. Предыдущая версия и её архив сохранены.
В V16.22 изменён путь сохранения и поведение при ошибке; новый режим ещё требует
запуска в SOLIDWORKS. Грамматика, API IsOpenedReadOnly, границы изменений и сборка
архива проверены в облаке; нативная компиляция VBA здесь недоступна.
