# Координатор Codex: SolidWorks 2025

## Минимальный контекст
1. Прочитать [каталог](topics/README.md); выбрать проект и его актуальный README.
2. Найти нужные функции, а не читать весь исходник/историю. Историю версий открывать только при конкретной проблеме.
3. Уточнить [доказанный статус](topics/evidence.md): пользовательский запуск, журнал SW, автоматический тест и гипотеза **не равноценны**.

## Три подагента (не запускать автоматически)
- **`coder`**: реализация и оптимизация; **только он из подагентов** правит явно назначенные исходники. Главный агент может сам выполнить простые правки.
- **`api_expert`**: только чтение; ищет официальные SolidWorks API-контракты, параметры, типы, COM/кодировки и ограничения SW2025.
- **`debugger`**: только чтение; воспроизводит доступные тесты, диагностирует логи, проверяет регрессии/откат, рекомендует конкретное исправление.
- Главный агент выбирает один/несколько профилей только при пользе. При небольшой задаче выполняет сам; не устраивает обязательный тройной аудит.
- Если подагенты недоступны в текущем клиенте, выполняет проверки сам, не имитируя их запуск. Кодекс-конфиг не гарантирует поддержку ролей во всех клиентах.
- Подагент возвращает кратко: **вывод, файл/функция, подтверждение, риск, статус native-проверки, действие**. Не запускает других агентов, не делает git push.

## Установленные факты
- `drawingmerger`: **V16.21** подтверждена пользователем 28.10.2026; создаёт отдельный MERGED. [Паспорт](../drawingmerger/WORKING_VERSION_V16_21.md). V16.22 меняет запись в основной документ и **не проверена нативно**.
- `weldment_drilling`: R7 подтверждена на пяти созданных/размеренных видах; текущая R17 содержит неподтверждённые в SW улучшения. [История](../weldment_drilling/WORKING_VERSION.md).
- `autosizedrilling`: C# 1.1.2 прошла автоматические тесты, но не подтверждена как нативная замена исходной DLL.

## Не нарушать
- Сохранять подтверждённые версии, архивацию, оригинальные SWP/DLL/CAD, связанные размеры/разрезы и текстовые связи заметок.
- Для новых COM-методов проверять реальные сигнатуры и эффект после вызова: `Nothing`, Boolean, выбор объекта, активный лист, частичную вставку.
- ANTLR, interop и Python-тесты не заменяют `Debug → Compile` и пробный запуск на **копии** в SolidWorks 2025.
- При изменениях в сохранении/экспорте защищать исходные файлы и проверять модель, конфигурацию, связи, PDF; не обходить Defender.
- Git push или merge в main — только с явного разрешения пользователя.
