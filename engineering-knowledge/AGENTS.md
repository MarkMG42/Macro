# Правила Codex для SolidWorks 2025

Цель: безопасно развивать макросы VBA/COM и C# без повторного изучения всей истории.

## Вход в задачу
1. Прочитай корневой `AGENTS.md` и [каталог](topics/README.md).
2. Определи **один** нужный проект: `drawingmerger/`, `weldment_drilling/`, `autosizedrilling/` или `DrillingView/`.
3. Прочитай только README проекта, страницу нужной области и конкретные функции исходника. Исторические версии и ZIP не открывай без причины.
4. Проверяй статус по [реестру доказательств](topics/evidence.md). Слова «собралось», «статические тесты прошли» и «работает в SW2025» — разные свидетельства.

## Подтверждённые опорные версии
- Объединение чертежей: **V16.21** (пользователь подтвердил 28.10.2026), создаёт отдельный MERGED. [Паспорт](../drawingmerger/WORKING_VERSION_V16_21.md).
- V16.22 меняет режим сохранения в основной чертёж, **не подтверждена** в SolidWorks. Не заменяй ею V16.21 автоматически.
- Сверловка: пользователь подтвердил R7 (5 видов/5 размеров), последующие R8–R17 содержат изменения, нативный результат R17 пока не подтверждён. [Паспорт](../weldment_drilling/WORKING_VERSION.md).
- AutoSizeDrilling: C# 1.1.2 — кандидат со статическими тестами, не подтверждённая нативная замена DLL.

## Экономия контекста и агенты
- Для простых задач используй **одного** основного агента.
- Сложные независимые вопросы делегируй только затронутым профилям из `engineering-knowledge/agents/*.toml`: `sw_drawings`, `sw_component_notes`, `sw_document_output`, `sw_dimensions`, `sw_vba_com`. Не вызывай все профили автоматически.
- `.codex/config.toml` задаёт CLI-роли, но не гарантирует их доступность в любом клиенте. При отсутствии spawn-инструмента проверь вопрос самостоятельно, не имитируй работу подагента.
- Подагент по умолчанию изучает исходники без правок; общий код меняет координатор. Не заводи новые роли без новой предметной области.

## Безопасность изменений
- Не меняй подтверждённые архивы/релизы, оригинальные DLL/SWP, пользовательские CAD/логи и защищённые исторические папки ради документации.
- Уточняй API SolidWorks по действительной сигнатуре и условиям использования; [VBA/COM](topics/vba-com.md). `Nothing`, COM Boolean, контекст листа/вида и неполные вставки требуют явной проверки.
- Статические/grammar/interop-тесты не заменяют `Debug → Compile` и запуск на копиях в SolidWorks 2025. Не утверждай native-успех без свидетельства.
- Перед публикацией: проверить сохранность моделей/конфигураций, зависимых видов, размеров, живых заметок, сохранения и PDF, если они затронуты.
- Git push/слияние в main — только с явного разрешения пользователя; не обходи защиту Windows/Defender.

## После значимой задачи
В существующей теме запиши **только** новое правило, функцию/путь, статус проверки, ключевую ошибку и ограничение. Не переносить туда диалог, весь лог и копии кода. При необходимости обнови `topics/evidence.md`. Проверка структуры: `python3 engineering-knowledge/tools/check_agent_knowledge.py`.
