## Статусы

Статусы независимы: одна запись может иметь несколько, каждый в своей области.

- **Проверено в SolidWorks** — есть конкретный результат реального запуска/журнала;
  указать документированный источник, среду и границы, не приписывать запуск облаку.
- **Подтверждено пользователем** — явное сообщение об успехе; не равно проверке всех случаев.
- **Проверено автоматически** — назвать конкретные тесты, артефакт/хеш и отсутствие SW.
- **Не проверено** — решение/гипотеза без требуемого испытания; не основание обещать работу.
- **Не работает** — конкретный отказ с условиями; не означает, что вся версия бесполезна.

При расхождении старого release README и более позднего паспорта рабочей версии
учитывай дату свидетельства. Не считай номер версии, наличие ZIP/SLDDRW или
статическое `true` в JSON доказательством успеха нативного алгоритма.

## Компактная запись

Используй существующий тематический раздел; новый файл нужен только новой области.

> ID и дата. Задача и условия. Статусы и доказательство. API и рабочий алгоритм.
> Реализация (относительный путь + функция). Ошибки/неудачные подходы и причина
> (доказана или гипотеза). Ограничения. Среда/объём проверки. Смежные применения.

Храни выводы, а не длинные логи/копии кода. При изменении рекомендации обновляй
запись, сохраняя объяснение прошлого отказа. Проверка базы без SW:
`python3 engineering-knowledge/tools/check_agent_knowledge.py`. Для сохранения между машинами нужны
обычные commit/синхронизация репозитория; автономного фонового обучения нет.
