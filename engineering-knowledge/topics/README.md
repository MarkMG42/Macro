## Статусы, которые нельзя смешивать
- **Подтверждено пользователем / журналом SolidWorks**: только указанный комплект, версия и сценарий.
- **Проверено автоматически**: сборка, тесты, парсер или interop без нативного запуска.
- **Не проверено**: требует проверки в SolidWorks.
- **Не работает**: воспроизведён конкретный отказ; это не приговор всем версиям.

## Запись нового знания
Коротко: `дата/версия → проблема → решение и функция → доказательство → ограничения`. Править существующий раздел, не плодить файлы или отчёты по каждому запуску. Не стирать причины известных ошибок.

**Ориентиры:** `drawingmerger/V16_21` — рабочая версия; `V16_22` — кандидат. `weldment_drilling` — текущий код R17, подтверждённая база R7. Для истории см. документы самих проектов. Проверка ссылок/профилей: `python3 engineering-knowledge/tools/check_agent_knowledge.py`.
