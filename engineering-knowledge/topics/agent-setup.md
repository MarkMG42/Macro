# Codex: передача контекста в новый чат

1. Прочитай корневой `AGENTS.md`, [каталог знаний](README.md) и только одну нужную тему.
2. Определи проект/версию по его README и [реестру проверок](evidence.md). Не сканируй все архивы и старые исходники.
3. В исходниках ищи конкретную функцию. Простую задачу выполняй основным агентом.
4. Для сложного межобластного вопроса подключи только нужные профили `engineering-knowledge/agents/*.toml`, возвращающие: вывод, подтверждение, риски и нативный статус. Без spawn-инструмента работай сам.
5. После значимой задачи кратко обнови существующую страницу знаний, не сохраняй всю историю отладки.

Конфигурация CLI: [`.codex/config.toml`](../../.codex/config.toml) — 5 ролей, максимум 4 потока, глубина 1. Не всякий облачный клиент применяет её автоматически; не обещай запуск агентов без инструмента. Не меняй модель/права, не создавай новую специализацию без фактической потребности.

**Маршруты:** зависимые виды → [drawings.md](drawings.md); заметки `$COMP`/SectionAssembly → [component-notes.md](component-notes.md); PDF, Save3 → [document-output.md](document-output.md); отверстия/размеры → [dimensions.md](dimensions.md); VBA, COM → [vba-com.md](vba-com.md).

**Контроль:** V16.21 подтверждена пользователем; V16.22 не подтверждена native. Сверловка R7 подтверждена на одном запуске, R17 не подтверждена. C# AutoSizeDrilling 1.1.2 — статически проверенный кандидат. Проверить структуру: `python3 engineering-knowledge/tools/check_agent_knowledge.py`, что не заменяет проверку в SolidWorks.
