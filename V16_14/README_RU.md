# V16.14 — эквивалентное чтение локального источника свойств

BUILD_ID: MERGE_DRAWINGS_V16_14_DEFAULT_PROPERTY_READBACK_20261027

## Обновление

После V16.11–V16.13 заменить ТОЛЬКО стандартный модуль содержимым
MERGE_DRAWINGS_V16_14.txt, выполнить Debug → Compile, сохранить .swp, запустить main.
Форма frmDrawingOrder и FORM_CODE.txt не изменены. При импорте BAS удалить старый
стандартный модуль, чтобы не осталось двух main/OrderPickFiles/OrderFolderFiles.
Использовать исходные сохранённые чертежи, не рабочие копии прошлого запуска.

При первой установке вставить стандартный модуль, создать пустую UserForm с
(Name)=frmDrawingOrder и вставить FORM_CODE.txt в код этой формы. Кнопки создаются
внутри VBA. Нет HTA или запуска внешних процессов.

## Что подтвердил журнал V16.13

Отключение наследования сработало. На проверенных добавленных листах, включая
лист с разрезами, модель источника свойств и конфигурация совпали с оригиналом.
На листе с разрезами запрос CustomPropertyView=[Разрез Б-Б] прочитан как
[По умолчанию]. Строгая строковая проверка остановила выполнение. Последующие
проверки четвёртого добавленного листа, сохранения, повторного открытия и PDF
ещё не выполнены. Полное успешное объединение по этому запуску не доказано.

V16.14 добавляет узкое правило проверки PropertyViewReadbackMatches:
- Оба режима должны быть локальными (SameCustomProp=False).
- Отличающееся прочитанное значение — только известная метка Default/По умолчанию
  или пустая строка, которую резолвер уже трактует как локальный режим по умолчанию.
- Запрошенный явный вид должен существовать в результате.
- Действительный вид, определённый через прочитанный режим, тоже должен существовать.
- У обоих видов модель и конфигурация должны совпасть с исходным источником свойств.
- Модель/конфигурация, записанные в снимке фактического листа, также должны совпасть.

Только тогда принимается эквивалентный источник тех же свойств модели. Выбор
другого именованного вида не принимается этим правилом. Неверная модель,
конфигурация, режим или отсутствующий вид по-прежнему вызывают остановку.
Подпись Default сама по себе не считается доказательством корректности.

В журнале появляется PROPERTY VIEW equivalent default с запрошенным, прочитанным
и фактически разрешённым именем вида. Правило используется и после сохранения/
повторного открытия. Изменены только VerifyDrawing и добавлен чистый helper;
копирование, перенос видов, локализация источников, основные проверки моделей,
геометрии, родителей и оформления, сохранение и экспорт PDF не изменены.
