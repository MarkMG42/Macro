# V16.16 — сохранять результат рядом с основным чертежом

BUILD_ID: MERGE_DRAWINGS_V16_16_DRAWING_FOLDER_20261027

## Обновление после рабочей V16.15

Заменить только стандартный модуль содержимым MERGE_DRAWINGS_V16_16.txt,
выполнить Debug → Compile, сохранить .swp и запустить main. Форму frmDrawingOrder
и FORM_CODE.txt не менять. При импорте BAS удалить предыдущий стандартный модуль,
чтобы не осталось дублирующихся main/OrderPickFiles/OrderFolderFiles.
Рабочая V16.15 сохранена без изменений под тегом v16.15-working.

## Куда сохраняются файлы

Базовая папка — папка ОСНОВНОГО чертежа, выбранного первым диалогом.
Расположение самого .swp больше не влияет на место вывода. Если источники
находятся в разных папках, результат всё равно рядом с основным чертежом.

Пример:

```text
D:\Проект\Чертежи\
  Основной.SLDDRW
  Источник.SLDDRW
  MERGED_20261027_140000.slddrw
  MERGED_20261027_140000.pdf
  runs\20261027_140000\
    merge.log
    STATUS.txt
    verified_views.tsv
    WORK_TARGET_20261027_140000.slddrw
    SOURCE_20261027_140000_0001.slddrw
    WORK_PDF.pdf
```

Итоговые SLDDRW/PDF находятся прямо в папке чертежей; временные копии и диагностика
— в runs. Сообщение об успехе и журнал показывают точные пути обоих результатов.
Для записи в выбранную папку должны быть обычные права записи. Если их нет,
макрос сообщит ошибку; скрытого возврата к папке макроса/«Тест» нет.

Совпадения имён с предыдущими запусками обходятся суффиксом _1, _2 и т. д.
Перед копированием имена проверяются повторно; существующие файлы не перезаписываются.
Защита рабочих файлов сохранена: вне runs разрешена обработка только нового,
точно зарегистрированного итогового SLDDRW, а не всех файлов папки исходников.
Оригиналы не перезаписываются.

Автоматический поиск чертежей в папке, включая «Добавить папку», пропускает
предыдущие MERGED_<8 цифр даты>_<6 цифр времени>*.slddrw. Иначе при следующем
запуске они могли бы случайно попасть в список источников. Явный ручной выбор
предыдущего результата не запрещён. Основной файл, дубли и ~$ исключаются как раньше.

Алгоритм объединения, проверка видов/родителей/штампов/штриховок, перестроение,
сохранение/повторное открытие, экспорт PDF и форма оставлены от рабочей V16.15.
Меняются только выбор путей, точное разрешение нового итогового файла и фильтр
автоматического списка. Внешние скрипты/процессы не добавлялись.

## Проверки

Проверены грамматика полного модуля, эквивалентность BAS/TXT, лимиты строк,
уникальность процедур, область изменений, сохранность рабочих артефактов V16.15,
неизменность формы/PDF-экспорта, проверки существования итоговых файлов перед
их регистрацией и целостность архива. Новый вариант сохранения здесь не запускался
в Windows/SOLIDWORKS; требуется обычный запуск на исходных сохранённых чертежах.
После него проверить расположение SLDDRW/PDF, STATUS=SUCCESS и внешний вид.

Для первой установки создать .swp, вставить стандартный модуль, добавить пустую
UserForm с (Name)=frmDrawingOrder и вставить FORM_CODE.txt в код формы. Кнопки
создаются внутри VBA. Поставка — исходники, не готовый бинарный .swp.
