# V16.8 — явный вид для свойств вместо локализованного Default

BUILD_ID: MERGE_DRAWINGS_V16_8_EXPLICIT_PROPERTY_VIEW_20261027

Журнал V16.7: исходный CustomPropertyView листа Лист1 — «По умолчанию»;
после PasteSheet и присваивания этой строки свойство осталось «Совпадает с листом,
указанным в Свойствах документа». Активация листа не устранила несовпадение.
Это разные режимы; их нельзя просто объявить равными или принять readback как эталон.
Сохранение результата и PDF ещё не выполнены.

Для известных режимов «По умолчанию»/«Default» исходного листа V16.8 выбирает
явный источник свойств: первый реальный вид этого листа. Его имя фиксируется
при CaptureDrawing исходного документа до временного перемещения разрезов,
затем преобразуется по viewMap. По текущему журналу это Чертежный вид1 →
Чертежный вид4 для первого добавленного листа. Восстановление свойства и
независимое построение ожидаемого снимка используют один расчёт по исходным
данным и проверенной карте видов, а не по фактическому readback свойства.

Реальное имя вида имеет приоритет, даже если совпало со специальной строкой.
Если Default указан у листа без видов или первый вид не сопоставлен,
выполнение останавливается. Неизвестные локализованные строки не угадываются.
Режим «Совпадает с листом...» на остальных листах сохранён без подмены:
эта корректировка не доказывает равенство значений всех полей штампов.

Остаётся строгая проверка CustomPropertyView после перестроения, сохранения
и повторного открытия. Добавлен PROPERTY VIEW resolve default с исходным и
новым видом. Диагностика before/readback/mismatch сохранена. Все проверки видов,
родителей, оформления и PDF остались. Изменены AppendDrawing, CaptureDrawing
и добавлен MappedPropertyView.

Установка: заменить весь код стандартного модуля содержимым
MERGE_DRAWINGS_V16.txt (UTF-8), либо импортировать MergeDrawingsV16.bas (CP1251)
вместо прежнего модуля. Не оставлять два модуля. Debug → Compile, сохранить .swp,
запустить main. Проверять BUILD_ID; имена файлов оставлены прежними.
Использовать исходные сохранённые чертежи, не рабочие копии неудачных запусков.

Здесь выполнены сборка BAS/TXT, эквивалентность кодировок, лимиты строк и
продолжений, уникальность процедур, проверка области изменения и неизменности
PDF-экспорта, целостность ZIP/SHA-256. Нативная компиляция VBA, чтение значений
полей штампа и запуск в SOLIDWORKS здесь не выполнялись.
Другие markdown/checks — исторические сведения. Исследовательские скрипты
требуют отсутствующего research-окружения.

Ожидаемый итог текущего комплекта: 5 листов, оба связанных разреза, SUCCESS,
