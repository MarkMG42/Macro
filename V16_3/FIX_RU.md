# V16.3 — выбор вида для переноса

BUILD_ID: MERGE_DRAWINGS_V16_3_VIEW_SELECTION_20261027

По журналу V16.2 рабочие копии созданы и проверены: основной документ имеет
1 лист / 3 вида, источник — 4 листа / 8 видов. У обоих разрезов А-А и Б-Б
подтверждён родитель Чертежный вид4 в копии источника. Затем произошёл отказ
SelectByID2 для Разрез Б-Б на этапе сбора семейства в рабочей копии источника.
Журнал не подтверждает перенос листов в итоговый документ: до него код не дошёл.
Финальные проверки, сохранение, повторное открытие и экспорт PDF не выполнялись.
Для этих входных данных ожидаются 5 листов, не 9 из исторического README V16.

Новый SelectViewForMove сначала выбирает найденный объект IView через MultiSelect2.
Если выбор не соответствует ожидаемому, выполняется прежний выбор по имени.
После каждого метода проверяется через SelectionMgr: выбран ровно один объект,
это IView, его имя и лист совпадают с ожидаемыми. Имена видов уникальны согласно
CaptureDrawing. Если ни один метод не дал нужный вид, EditCut не выполняется.
Журнал содержит SELECT VIEW object/name и SELECT CHECK count/type/view.
Сам факт отказа выбора по имени подтверждён; почему SOLIDWORKS отклонил имя,
из старого журнала установить нельзя. Объектный выбор требует нативного испытания.

Установка: полностью заменить код прежнего стандартного модуля содержимым
MERGE_DRAWINGS_V16.txt (UTF-8) либо импортировать MergeDrawingsV16.bas (CP1251)
вместо него. Не оставлять оба модуля. Выполнить Debug → Compile, сохранить .swp,
запустить main и проверить новый BUILD_ID. Имена файлов оставлены прежними.

Сохранены исправления V16.1/V16.2 и проверки графа видов, геометрии, аннотаций,
сохранения и повторного открытия. Обработка касается рабочих копий.

Проверки здесь: сборка BAS/TXT и их эквивалентность, ограничения строк и
продолжений, уникальность процедур, неизменность экспорта PDF относительно V16.2,
CRC ZIP и SHA-256. Существование MultiSelect2 и методов SelectionMgr и их
число параметров сверены с метаданными SolidWorks.Interop.sldworks 32.1.0.
Это ABI SW 2024, не компиляция VBA и не запуск SOLIDWORKS 2025.
Остальные markdown/checks относятся к историческим версиям и не подтверждают
проверку V16.3. Старые исследовательские скрипты требуют отсутствующего research.

Для проверки повторить тот же запуск. Нужны SUCCESS, 5 листов, оба разреза
на предназначенном листе с прежним родителем, итоговый чертёж и PDF.
Если снова FAILED, передать полный новый merge.log, особенно SELECT VIEW/CHECK.
