# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.13](SOLIDWORKS_MERGE_V16_13_VBA_FORM.zip)

[Инструкция и исправление](V16_13/README_RU.md).

После V16.11/V16.12 заменить только стандартный модуль текстом
MERGE_DRAWINGS_V16_13.txt. Форма frmDrawingOrder не изменена.

Журнал V16.12 подтвердил смену модели свойств добавленных листов из-за общего
наследования от первого листа итогового документа. V16.13 отключает это
наследование только у добавляемых листов и задаёт явный источник по исходной
модели/конфигурации. Основной лист и настройки документа остаются прежними.
Строгая проверка модели/конфигурации сохранена, включая повторное открытие.

Интерфейс — встроенная VBA-форма с кнопками Вверх/Вниз. Нет внешнего скриптового
окна и запуска процессов. Грамматика и состав изменений проверены; нативный
запуск нового назначения источников свойств ещё требуется. После SUCCESS
сравнить штампы с исходниками. Предыдущие версии остаются в истории.
