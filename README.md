# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.18 — сохранение прямо в итоговый файл](SOLIDWORKS_MERGE_V16_18_VBA_FORM.zip)

[Установка, режимы проверки и изменения](V16_18/README_RU.md).

Для обновления заменить только основной модуль текстом MERGE_DRAWINGS_V16_18.txt.
Форма frmDrawingOrder не менялась.

V16.18 объединяет листы сразу в новом MERGED_….slddrw рядом с основным чертежом:
без отдельного WORK_TARGET, последующего копирования и повторного Save3 по умолчанию.
Убраны повторное полное перестроение перед сохранением и лишние активации документа.
Исходные файлы защищены. Разрезы, связанные заметки и источники свойств переносятся
по алгоритму V16.17; копии источников нужны только при межлистовых родительских связях.

По умолчанию после Save3 проверяется открытый документ; автоматическое повторное
открытие не выполняется. Его можно включить константой VERIFY_AFTER_SAVE=True.
Это существенное отличие от V16.17: быстрый SUCCESS не подтверждает проверку файла
после повторного открытия. Результат V16.18 и ускорение ещё требуют запуска в SOLIDWORKS.

Журнал V16.17 подтвердил успешную проверку 25 листов/70 видов и экспорт PDF. Сам Save3
в сумме занял 48 секунд; дополнительные перестроения и повторное открытие — несколько
минут. Исходный журнал и личные файлы в репозиторий не включены.
