# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.22 — сохранить в основном чертеже](SOLIDWORKS_MERGE_V16_22_VBA_FORM.zip)

[Установка, резервная копия и восстановление](V16_22/README_RU.md).
Заменить только стандартный модуль текстом MERGE_DRAWINGS_V16_22.txt;
форма frmDrawingOrder не менялась.

Результат сохраняется в выбранном основном .SLDDRW, по прежнему пути и имени.
Перед изменениями создаётся runs/<запуск>/BACKUP_MAIN.slddrw. Отдельного итогового
MERGED-чертежа нет. Добавляемые исходники не перезаписываются. PDF рядом с основным
имеет отдельное имя с отметкой времени; существующие PDF не перезаписываются.

При ошибке непроверенный основной документ дополнительно не сохраняется.
Если Save3 уже начался, основной файл на диске мог измениться — резервная копия
позволяет восстановить исходное состояние. Автоматического отката нет.
Повторный запуск добавляет листы повторно; перед повторением восстановите исходник.

Работа разрезов и связанных заметок V16.21 подтверждена пользователем; этот код
в V16.22 не менялся. Новый режим сохранения ещё нужно проверить в SOLIDWORKS.
[Рабочая V16.21 с отдельным MERGED-файлом](SOLIDWORKS_MERGE_V16_21_VBA_FORM.zip)
сохранена без изменений.

По умолчанию VERIFY_AFTER_SAVE=False: проверяется открытый документ после Save3,
без повторного открытия. True включает дополнительную проверку после открытия.

Предыдущие [V16.17](SOLIDWORKS_MERGE_V16_17_VBA_FORM.zip) и
[V16.16](SOLIDWORKS_MERGE_V16_16_VBA_FORM.zip) сохранены без изменений.
Рабочая, подтверждённая пользователем V16.15 сохранена под тегом v16.15-working:
[архив](https://github.com/MarkMG42/Macro/raw/refs/tags/v16.15-working/SOLIDWORKS_MERGE_V16_15_VBA_FORM.zip),
[паспорт версии](WORKING_VERSION.md).

## Отдельная проверка заметок

[Диагностика «Связать со свойством → Наименование»](diagnostics/linked_notes/README_RU.md).
Читает заметки активного документа и создаёт TSV без сохранения чертежа. Отчёты могут
содержать личные пути и текст; не публикуйте их в открытом репозитории.
