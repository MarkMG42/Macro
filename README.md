# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.19 — проверка привязок заметок на разрезах](SOLIDWORKS_MERGE_V16_19_VBA_FORM.zip)

[Установка и изменения](V16_19/README_RU.md).
Заменить только стандартный модуль текстом MERGE_DRAWINGS_V16_19.txt;
форма frmDrawingOrder не менялась.

В журнале V16.18 перенос разрезов завершился, затем проверка привязки заметки
остановила объединение. V16.19 читает компонент с учётом чертёжного вида,
обновляет живую ссылку перед повторной строгой проверкой и записывает сравниваемые
привязки в журнал. Точная причина отличия в старом журнале не видна; исправление
требует проверки в SOLIDWORKS на исходных чертежах.

Оптимизации V16.18 сохранены: объединение прямо в новый MERGED рядом с основным
чертежом, без WORK_TARGET и повторного открытия по умолчанию. После Save3 проверяется
открытый документ. Повторное открытие можно включить через VERIFY_AFTER_SAVE=True.
Первый результат проверьте также после ручного открытия.
