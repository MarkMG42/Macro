# Макрос чертежей SOLIDWORKS

[Текущий вариант V16.11 — встроенная форма VBA](SOLIDWORKS_MERGE_V16_11_VBA_FORM.zip)

[Инструкция установки](V16_11/README_RU.md).

Это новая реализация списка: кнопки Вверх/Вниз, удаление и добавление файлов,
подтверждение и отмена. Нет внешнего скриптового окна и запуска процессов.
Перетаскивание заменено кнопками; команд сортировки через InputBox нет.
Алгоритм объединения оставлен из V16.10.

Комплект состоит из стандартного модуля и кода UserForm. В редакторе VBA нужно
один раз создать пустую форму с именем frmDrawingOrder и вставить FORM_CODE.txt;
кнопки создаются автоматически внутри формы. Сам VBA-проект программно не меняется.
Это исходники, не бинарный .swp. Подробные шаги — в инструкции.

Проверка грамматики обоих модулей прошла. Нативная компиляция, работа формы в
Windows/SOLIDWORKS и антивирусная проверка здесь не выполнялись. Это не гарантия
прохождения Defender. Если новая версия блокируется, не обходите защиту.
Предыдущие версии остаются в репозитории/истории и не входят в текущий комплект.
