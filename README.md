# Макрос чертежей SOLIDWORKS — V16.9

[Скачать текущий комплект](SOLIDWORKS_MERGE_V16_9_NATIVE_DIALOGS.zip)

[Установка и команды окна списка](V16_9/README_RU.md).

Окно сортировки заменено на стандартные InputBox/MsgBox VBA. Запуска внешних
процессов и прежнего скриптового окна в текущем модуле нет. Команды: OK — принять,
M 3 1 — переместить, R 2 — удалить из списка, A — добавить файлы, F — папку,
V 2 — полный путь, N/P — страницы. Перетаскивание заменено командами.

Код объединения — V16.8, кроме BUILD_ID; нативная проверка последнего исправления
свойств листа ещё не завершена. Есть проверка грамматики и статические проверки,
но нет запуска новых диалогов в Windows, компиляции SOLIDWORKS VBA или
антивирусного заключения. Не отключайте защиту ради запуска.

Старые комплекты убраны из текущей ветки после сообщения о срабатывании Defender.
Они сохранены в истории Git; не используйте их для новой установки.
