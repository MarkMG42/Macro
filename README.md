# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.21 — нативные адреса заметок разрезов](SOLIDWORKS_MERGE_V16_21_VBA_FORM.zip)

[Установка и изменения](V16_21/README_RU.md). Заменить только стандартный модуль
текстом MERGE_DRAWINGS_V16_21.txt; форма frmDrawingOrder не менялась.

V16.20 записывала неразрешимую ссылку: имя модели вместо полного экземпляра,
отображаемое имя разреза вместо внутреннего. Расширенный аудит позволил заменить
это построением по полной DrawingComponent.Name привязки и View.GetUniqueName.
Служебные сборки SectionAssembly и номера экземпляров сохраняются. На отчёте исходного
А-А формат точно воспроизводит существующую рабочую ссылку. Нативный запуск V16.21
и разрешимость новых ссылок после переноса ещё нужно подтвердить в SOLIDWORKS.
Проверки текста и привязок не отключены.

Сохранение и перенос разрезов не менялись. Новый MERGED — рядом с основным чертежом,
один Save3 без повторного открытия по умолчанию. VERIFY_AFTER_SAVE=True включает
дополнительную проверку после открытия. Первый результат проверьте после ручного открытия.

## Отдельная проверка заметок

[Диагностика «Связать со свойством → Наименование»](diagnostics/linked_notes/README_RU.md).
Читает заметки активного документа и создаёт TSV без сохранения чертежа. Отчёты могут
содержать личные пути и текст; не публикуйте их в открытом репозитории.
