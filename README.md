# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.15](SOLIDWORKS_MERGE_V16_15_VBA_FORM.zip)

[Инструкция и исправление](V16_15/README_RU.md).

После V16.11–V16.14 заменить только стандартный модуль текстом
MERGE_DRAWINGS_V16_15.txt. Форма frmDrawingOrder не изменена.

V16.14 прошла проверку 5 листов/11 видов и связей обоих разрезов до сохранения
и после повторного открытия рабочего файла. Проверка итоговой копии остановилась
на количестве штриховок. В финальном открытии отсутствовало перестроение.
V16.15 добавляет его перед проверкой и сохраняет проверенную итоговую копию
перед прежним экспортом PDF. Строгое сравнение штриховок остаётся; при несовпадении
в журнал выводятся ожидаемые и фактические числа.

Интерфейс — встроенная VBA-форма с кнопками Вверх/Вниз. Нет внешнего скриптового
окна и запуска процессов. Грамматика и последовательность действий проверены;
нативный запуск нового этапа ещё требуется. Результат должен иметь SUCCESS,
сохранённые SLDDRW/PDF и совпадать с исходниками по оформлению и штампам.
