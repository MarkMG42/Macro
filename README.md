# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.12](SOLIDWORKS_MERGE_V16_12_VBA_FORM.zip)

[Инструкция и исправление](V16_12/README_RU.md).

После V16.11 достаточно заменить основной модуль текстом
MERGE_DRAWINGS_V16_12.txt. Форма frmDrawingOrder и её код не изменились.

Исправлено противоречие проверки: при наследовании источника свойств листа
больше не требуется имя явного локального вида. Вместо подписи режима
проверяются действительные модель и конфигурация источника свойств с учётом
настроек документа. Локальный режим сохраняет проверку точного имени вида.

Сортировка остаётся во встроенной форме VBA кнопками Вверх/Вниз.
В текущем комплекте нет внешнего скриптового окна и запуска процессов.
Проверены грамматика и состав изменений. Нативная компиляция и запуск новой
проверки в SOLIDWORKS здесь не выполнялись. Результат не подтверждён до SUCCESS
и сравнения штампов с исходниками. Предыдущие версии остаются в истории.
