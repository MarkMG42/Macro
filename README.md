Итоговые MERGED_….slddrw и MERGED_….pdf сохраняются прямо в папку выбранного
основного чертежа. Рабочие копии и журнал — в её подпапку runs. Расположение
самого .swp на место вывода больше не влияет. Автоматический поиск источников
пропускает результаты предыдущих запусков с именем MERGED_<дата>_<время>….

Для обновления заменить только основной модуль текстом MERGE_DRAWINGS_V16_16.txt.
Форма frmDrawingOrder не менялась. Алгоритм объединения и проверки сохранены.
Грамматика и новые пути проверены статически; запись нового варианта в Windows/
SOLIDWORKS ещё требует запуска.
