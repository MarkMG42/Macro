# Макрос объединения чертежей SOLIDWORKS

В полученном запуске V16.20 заметки SectionAssembly остались пустыми: построенная
ссылка не разрешилась после перестроения. [Расширенный аудит внутренних адресов](diagnostics/linked_notes_context/README_RU.md)
собирает данные для следующего исправления без повторного объединения.

[Скачать V16.20 — ссылки заметок разрезов](SOLIDWORKS_MERGE_V16_20_VBA_FORM.zip)

[Установка и изменения](V16_20/README_RU.md). Заменить только стандартный модуль
текстом MERGE_DRAWINGS_V16_20.txt; форма frmDrawingOrder не менялась.

Добавлено восстановление пустых ссылок SectionAssembly по фактическому дереву
компонентов вида результата. Поддерживается одна привязка и один $COMP; экземпляр
определяется по точному пути, конфигурации и полному имени. Проверки текста и привязок
сохранены. Запуск в SOLIDWORKS здесь недоступен; результат требует проверки пользователем.

Оптимизации V16.18 сохранены: новый MERGED рядом с основным чертежом, один Save3,
без повторного открытия по умолчанию. VERIFY_AFTER_SAVE=True включает дополнительную
проверку после открытия. Первый результат проверьте также после ручного открытия.

## Отдельная проверка заметок

[Диагностика «Связать со свойством → Наименование»](diagnostics/linked_notes/README_RU.md).
Читает заметки активного документа и создаёт TSV без сохранения чертежа. Отчёты могут
содержать личные пути и текст; не публикуйте их в открытом репозитории.
