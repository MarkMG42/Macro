# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.14](SOLIDWORKS_MERGE_V16_14_VBA_FORM.zip)

[Инструкция и исправление](V16_14/README_RU.md).

После V16.11–V16.13 заменить только стандартный модуль текстом
MERGE_DRAWINGS_V16_14.txt. Форма frmDrawingOrder не изменена.

V16.13 сохранила исходную модель свойств добавленных листов, но остановилась
на строковом readback: для разреза вернулось «По умолчанию». V16.14 принимает
такой локальный режим лишь при наличии обоих видов и подтверждённом совпадении
модели/конфигурации с оригиналом. Неправильные источники и именованные
несовпадения по-прежнему отклоняются. Сохранение/PDF и перенос видов не изменены.

Интерфейс — встроенная VBA-форма с кнопками Вверх/Вниз. В текущем комплекте
нет внешнего скриптового окна и запуска процессов. Грамматика и состав изменений
проверены; нативный запуск нового правила ещё требуется. Ожидаемый результат
текущего комплекта — 5 листов и SUCCESS; штампы нужно сравнить с исходниками.
