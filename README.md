# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.6](SOLIDWORKS_MERGE_V16_6_COM_BOOLEAN.zip)

Исправлена обработка Boolean из COM: центральная проверка Require больше
не использует побитовый Not. Исправлены условие резервного перестроения,
проверка несохранённых исходников и нормализация флагов при сравнении.
В REBUILD добавлены числовые ответы API.
Исходники и инструкция: [V16_6/FIX_RU.md](V16_6/FIX_RU.md).

Журнал V16.5 показал True у обоих методов, но код вошёл в ветку отказа.
Предполагается неканонический Boolean +1; числовое значение ещё нужно подтвердить.
Выполнены статические проверки, числовая модель Boolean и проверка ZIP.
Компиляция VBA и запуск в SOLIDWORKS не выполнялись.
Полное объединение пока не подтверждено. Для текущего комплекта ожидаются 5 листов.
