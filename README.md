# Макрос объединения чертежей SOLIDWORKS

[Скачать V16.17 — новый вариант для проверки](SOLIDWORKS_MERGE_V16_17_VBA_FORM.zip)

[Установка, изменения и ограничения](V16_17/README_RU.md).

Заменить только стандартный модуль текстом MERGE_DRAWINGS_V16_17.txt.
Форма frmDrawingOrder не менялась. Итоговый чертёж и PDF сохраняются рядом с основным
чертежом, рабочие файлы и журнал — в runs.

В V16.17 отдельная копия источника нужна только для разрезов/выносных видов, родители
которых находятся на других листах. Убраны повторные перестроения старых листов и
лишний промежуточный цикл открытия/сохранения. Для свойств сборки на листе с видами
деталей при необходимости создаётся скрытый служебный вид нужной модели. Добавлены
восстановление и проверка компонентных ссылок заметок, их текста, слоя и привязок.
При ошибке рабочий чертёж остаётся открытым, выполняется попытка сохранить частичный
результат в runs. STATUS при этом остаётся FAILED.

Грамматика и сигнатуры API проверены. Нативная компиляция VBA и запуск SOLIDWORKS
здесь недоступны; исправление ещё нужно проверить на полном наборе исходников.
Сохранение наименований на всех компьютерах не подтверждено.

Предыдущая [V16.16](SOLIDWORKS_MERGE_V16_16_VBA_FORM.zip) сохранена без изменений.
Рабочая, подтверждённая пользователем V16.15 сохранена под тегом v16.15-working:
[архив](https://github.com/MarkMG42/Macro/raw/refs/tags/v16.15-working/SOLIDWORKS_MERGE_V16_15_VBA_FORM.zip),
[паспорт версии](WORKING_VERSION.md).

## Отдельная проверка заметок

[Диагностика «Связать со свойством → Наименование»](diagnostics/linked_notes/README_RU.md).
Она читает заметки активного документа и создаёт отчёт TSV, не изменяя макрос
объединения и не сохраняя чертёж. Отчёты могут содержать частные пути и текст:
не публикуйте их в открытом репозитории.
