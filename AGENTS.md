# Вход для Codex — SolidWorks 2025

1. Прочитай [краткие правила координатора](engineering-knowledge/AGENTS.md) и [каталог знаний](engineering-knowledge/topics/README.md).
2. Определи проект, открой его README и **только относящиеся к задаче** функции и темы. Не загружай весь Git, архивы, старые версии и логи.
3. Главный Codex — координатор. При необходимости привлекай **до трёх** ролей: `coder`, `api_expert`, `debugger` ([конфиг](.codex/config.toml)). Простое изменение выполняй без подагентов.
4. Чётко разделяй успешные проверки в SolidWorks и статические тесты. Не изменяй рабочие релизы ради новой экспериментальной версии.

Проекты: [объединение](drawingmerger/README.md), [сверловка](weldment_drilling/README_RU.md), [размеры](autosizedrilling/README.md), [DrillingView](DrillingView/README.md). Знания: `engineering-knowledge/topics/*.md`, исходники — в папках проектов.

**Git push/слияние в main — только по явному разрешению пользователя.**
