# V16.11 — встроенная форма VBA

BUILD_ID: MERGE_DRAWINGS_V16_11_VBA_FORM_20261027

Это новая реализация интерфейса, а не переупаковка заблокированного макроса.
Список находится внутри обычной VBA UserForm: Вверх, Вниз, Убрать, Добавить файлы,
Добавить папку, Продолжить, Отмена. Команд сортировки через InputBox нет;
перетаскивание заменено кнопками. Ввод пути папки по кнопке «Добавить папку»
использует стандартный InputBox. Выбор файлов — стандартный файловый диалог.

Нет HTA, JavaScript, mshta.exe, запуска внешних процессов, скачивания компонентов
и программного изменения VBA-проекта. Элементы формы создаются встроенной
библиотекой Microsoft Forms; FileSystemObject/Dictionary и API SOLIDWORKS остаются.
Это не отказ от COM и не антивирусная сертификация. Обнаружение Defender не
расшифровано; отсутствие срабатывания новой версии здесь не подтверждено.

## Установка: один стандартный модуль и одна пустая форма

Поставка — исходники, не готовый .swp. В этой Linux-среде нет редактора SOLIDWORKS
для создания бинарного проекта. Не переименовывать TXT/BAS в SWP.

1. В SOLIDWORKS создать новый макрос .swp в отдельной папке. Старые модули
   заблокированных версий не переносить. Защиту Windows не отключать.
2. В редакторе VBA полностью заменить стандартный модуль текстом
   MERGE_DRAWINGS_V16_11.txt (UTF-8). Альтернатива — импортировать
   MergeDrawingsV16_11.bas вместо автоматически созданного стандартного модуля.
3. Выбрать Insert → UserForm. Открыть окно Properties (F4) и изменить именно
   свойство (Name) новой формы на frmDrawingOrder. Не только Caption.
4. Открыть код этой формы (F7), удалить пустые обработчики и вставить весь
   FORM_CODE.txt. Кнопки и список вручную рисовать не нужно: они создаются
   кодом формы. Код формы нельзя вставлять в стандартный модуль.
5. Проверить стандартные References SOLIDWORKS 2025 и swconst. Библиотека
   Microsoft Forms обычно подключается редактором при добавлении UserForm.
   Если компонента нет или политика организации блокирует VBA, обратиться
   к администратору; DLL из интернета не скачивать, политики не обходить.
6. Debug → Compile, сохранить .swp, запускать main стандартного модуля.
7. Использовать исходные сохранённые чертежи, не рабочие копии прошлых запусков.
   Выделить строку, нажимать Вверх/Вниз, затем Продолжить. Основной чертёж первым.
   Крестик или Отмена отменяет объединение. Дополнительные процессы не запускаются.

Алгоритм объединения совпадает с V16.10, кроме BUILD_ID. Включено последнее
восстановление режима источника свойств листа; его нативная проверка ещё нужна.
Для текущего комплекта ожидаются 5 листов, связи обоих разрезов, заполненные
штампы, SUCCESS, итоговый SLDDRW и PDF. При ошибке передать новый merge.log.

## Проверки и ограничения

BAS/TXT проверяются на эквивалентность, лимиты и уникальность процедур.
CAD-ядро сверяется с V16.10. Стандартный модуль и код формы проверяются независимой
грамматикой VBA; это не проверка контекстных типов/WithEvents редактором VBA.
Контрольные суммы и проверки находятся в checks. Обработка событий формы,
расположение элементов, загрузка Microsoft Forms, компиляция и работа на Windows
здесь не проверены. Антивирусное сканирование не выполнено.

Если защита блокирует новую реализацию, остановиться и обратиться к администратору.
Другой формат файла, ручное копирование кода или снятие блокировки не являются
подтверждением безопасности и не должны использоваться для обхода обнаружения.
