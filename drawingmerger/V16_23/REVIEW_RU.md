# Обновление V16.23: один финальный обход

BUILD_ID: `MERGE_DRAWINGS_V16_23_SINGLE_FINAL_AUDIT_20261111`.

По запросу пользователя повторные полные обходы основного чертежа при объединении удалены. В `main` один свежий `CaptureDrawing` и `VerifyDrawing` выполняются перед единственным Save3. После Save3 нет обхода, повторного открытия или повторной проверки. Манифест относится к состоянию перед сохранением, а не подтверждает состояние на диске.

`AppendDrawing` читает после импорта только листы текущего источника через `CaptureMappedSheets`; этот снимок используется для новых native-меток разрезов и служебных видов. Общий аудит отложен до завершения всех вставок. `MoveView` сравнивает структуру только двух затронутых листов до и после перемещения. Отсутствующий в частичном снимке родитель допустим: реальное наличие и связь проверяются финальным полным аудитом. В частичном снимке не вычисляется источник свойств через другие листы; итоговая проверка выполняет это по всему документу.

Первичное полное чтение основного документа сохранено для эталона. Чтение исходных документов и рабочих SOURCE-копий сохранено: оно нужно для графа родителей и сохранности переносимого содержимого. Чтение списка имён всех листов не активирует их. Обязательные перестроения добавленных и изменённых листов сохранены; прямой rebuild сборки запрещён проверкой типа.

Остались оптимизации предыдущего кандидата: пропуск лишнего поиска видов directSource, индекс имён листов rebuild, удаление неиспользуемого диалога сохранения/переменных, явный список листов PDF, WORK_PDF с проверкой и резервом предыдущего PDF, точные итоговые сообщения и резервный журнал ранних ошибок.

Ограничения: повреждение ранее добавленного листа может быть обнаружено только перед Save3. Изменение заметок самим Save3 или PDF-экспортом после финального аудита теперь автоматически не проверяется — это выбранный пользователем режим. PDF-файл проверяется по результату API и размеру, но не по содержимому страниц. Отказ PDF не откатывает уже сохранённый чертёж. Скорость и корректность новой схемы в SolidWorks ещё не проверены.

API PDF: [SetSheets](https://help.solidworks.com/2025/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IExportPdfData~SetSheets.html). Статическая проверка грамматики не заменяет Debug → Compile VBAProject и запуск на копии комплекта в SolidWorks 2025. Рабочий архив V16.22 неизменён.
