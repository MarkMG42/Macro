# V16.25: экспериментальные ускорения

Основа V16.24 с таймером (beb152f3c179a7743da9aa4144e190efca1cf15e), неизменная в соседней папке. Изменены main (жизненный цикл перерисовки), AppendDrawing (только метки подробного таймера), CloneInput/PrepareSource (исключён повторный снимок и reopen оригинала), RestoreImportedLinkedNotes (ранний пропуск пустых коллекций), RebuildDrawing (обычный rebuild с принудительным fallback). Остальные существующие процедуры сохранены, кроме идентификаторов версии.

CloneInput не владеет переданным оригиналом: закрытие/восстановление его листа выполняет PrepareSource через ReleaseSource. При отказе временная копия закрывается, пользовательский оригинал не сохраняется и не закрывается. При успехе копия проверяется полным CaptureDrawing + VerifyDrawing до освобождения оригинала. Несохранённый оригинал копируется через SaveAs Copy как прежде; путь исходника проверяется.

Перерисовка отключается только у ModelDoc2.ActiveView основного чертежа. Сохраняется нормализованный Boolean EnableGraphicsUpdate. Состояние отмечается как удерживаемое до записи False, чтобы даже частичный отказ направлялся в восстановление. Восстановление подтверждается readback; ошибка журналируется, на штатном пути блокирует сохранение. Обработчик отказа и Finished повторно пытаются восстановить состояние. Возможности API не гарантируют нативный результат при сбоях COM — это требует теста в SW2025.

Новые DETAIL-строки — интервалы внутри SOURCE, не дополнительные расходы для суммирования. TOTAL и прежние основные этапы остаются сопоставимыми; отдельно учтено GRAPHICS_RESTORE.

Проверка native обязательна: простые листы, межлистовые семьи разрезов, источник с несохранёнными изменениями, открытый пользователем источник, ошибочное создание копии, отказ импорта, восстановление графики после отказа. Сравнивать V16.24 и V16.25 на одинаковых свежих копиях. Подробности и переключатели — README_RU.md.

Контракты SW2025:
- [EditRebuild3](https://help.solidworks.com/2025/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelDoc2~EditRebuild3.html): активный документ, Boolean результата.
- [EnableGraphicsUpdate](https://help.solidworks.com/2025/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelView~EnableGraphicsUpdate.html): обновление модельного окна, в том числе при выборе объектов.

Нативный запуск и ускорение V16.25 не проверены. Статические проверки не заменяют Compile VBAProject и визуальную проверку штриховок/разрезов.
