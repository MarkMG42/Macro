# Установка и запуск

Для SOLIDWORKS 2025. Выберите архив в [README](README.md) и распакуйте его.
`.bas` импортируется в редактор VBA; SOLIDWORKS запускает сохранённый `.swp`.

## Обновить существующий макрос

1. Сервис → Макрос → Изменить: откройте тот `.swp`, который будете запускать.
2. В редакторе VBA удалите старый стандартный модуль объединения. Другие макросы не удаляйте.
3. File → Import File: импортируйте `.bas` из выбранного архива. Старый и новый модули объединения не должны оставаться вместе.
4. В форме `frmDrawingOrder` замените весь код содержимым `FORM_CODE.txt` из того же архива.
5. Debug → Compile VBAProject. Сохраните `.swp`.

## Создать макрос с нуля

1. Сервис → Макрос → Создать: создайте `.swp`.
2. Удалите автоматически созданный пустой стандартный модуль, импортируйте `.bas` через File → Import File.
3. Insert → UserForm. В свойствах задайте `(Name) = frmDrawingOrder`.
4. Откройте код формы и вставьте `FORM_CODE.txt`. Кнопки создаются кодом, рисовать их вручную не нужно.
5. Debug → Compile VBAProject. Сохраните `.swp`.

## Запуск

1. Сервис → Макрос → Выполнить: выберите сохранённый `.swp`, процедуру `main`.
2. Выберите основной `.slddrw`, затем добавляемые чертежи и их порядок.
3. Дождитесь сообщения об успешном завершении. Проверьте листы, размеры, разрезы, заметки и PDF.

Последняя версия записывает результат в основной чертёж, без бэкапа. PDF с его исходным именем заменяет существующий файл. Добавляемые исходники не сохраняются.
V16.21 создаёт отдельный MERGED-чертёж.

При повторном запуске листы добавляются повторно. После отказа до сохранения закройте частичный результат без сохранения и заново откройте исходный основной чертёж. После начала сохранения автоматического отката нет.

## Если произошла ошибка

Пришлите `merge.log` и `STATUS.txt` из папки `runs/<папка запуска>` рядом с основным чертежом.
Первая строка журнала показывает `BUILD_ID` запущенной сборки.

Для диагностики размеров импортируйте [AuditDrawingDimensions.bas](diagnostics/AuditDrawingDimensions.bas) отдельным модулем. Откройте исходник и результат после ошибки, запустите `AuditDrawingDimensions` через F5 в редакторе VBA. Пришлите `DimensionsAudit_….tsv`, созданный рядом с активным чертежом. Диагностика не сохраняет чертежи и не вызывает явного перестроения.
