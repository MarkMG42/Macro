# Объединение чертежей SOLIDWORKS 2025

**Рекомендуемая версия — V16.25.** Пользователь подтвердил успешную работу и выбрал её для дальнейшего использования после сравнения с V16.26. Код и архив V16.25 сохранены без изменений.

[Скачать V16.25](V16_25/SOLIDWORKS_MERGE_V16_25_FAST_EXPERIMENT_VBA_FORM.zip) · [Установка, запуск и таймер](V16_25/README_RU.md)

- Листы добавляются в выбранный основной чертёж; он сохраняется один раз после полного финального аудита.
- PDF всех листов сохраняется автоматически рядом с основным чертежом. Предыдущий PDF сохраняется в папке запуска перед заменой.
- Время работы и этапов — в `runs/<запуск>/TIMING.tsv` и `merge.log`. TOTAL исключает выбор файлов и ожидание закрытия итогового сообщения.
- Итоговые сообщения: «выполнено успешно» или «ошибка, проверьте журнал».
- Основной чертёж изменяется непосредственно; его резервная копия не создаётся. Повторный запуск повторно добавляет листы. Для сравнения скорости нужны одинаковые свежие копии комплекта.
