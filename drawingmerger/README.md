В последней версии:

- PDF рядом с основным чертежом, с тем же именем; существующий PDF заменяется.
- Несохранённые изменения принимаются. Бэкап отключён, основной чертёж сохраняется один раз после проверки.
- Допуск размещения видов и заметок — 30 мм по каждой оси.
- Отсутствие подтверждённого ошибочного RD18 = 532 мм фронтального вида модели «УОВН-65-65-1-2-РР из со» разрешено. Остальные размеры, текст заметок и связи проверяются.

Текущая сборка: `MERGE_DRAWINGS_V16_22_APPROVED_RD18_20261111`.
Архив содержит только `.bas` и код формы. Готового `.swp` нет.

При ошибке нужны `merge.log` и `STATUS.txt` из папки запуска `runs`.
Для сравнения размеров — [диагностический модуль](diagnostics/AuditDrawingDimensions.bas).
