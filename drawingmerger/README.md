# Макрос объединения чертежей SolidWorks

Все папки версий, ZIP-выпуски и паспорта рабочего варианта из корня репозитория
собраны здесь. Содержимое перенесено без изменения байтов.

**Рекомендуемый рабочий вариант — V16.21**:
[ZIP](SOLIDWORKS_MERGE_V16_21_VBA_FORM.zip), [инструкция](V16_21/README_RU.md),
[паспорт подтверждения](WORKING_VERSION_V16_21.md).
Для существующего .swp заменить стандартный модуль текстом
[V16_21/MERGE_DRAWINGS_V16_21.txt](V16_21/MERGE_DRAWINGS_V16_21.txt), выполнить
Debug → Compile и сохранить .swp. Форма frmDrawingOrder остаётся прежней;
при первой установке нужен её [код](V16_21/FORM_CODE.txt).
Готового бинарного .swp в этом комплекте нет.

Другие версии сохранены как история разработки, а не объявлены все рабочими:

- V16.15 — ранняя версия, подтверждённая пользователем на его комплекте;
  [паспорт](WORKING_VERSION.md).
- V16.17 — ранее зафиксирован SUCCESS на 25 листах/70 видах, медленно;
  [разбор запуска](V16_18/README_RU.md).
- V16.22 — сохранение непосредственно в основном файле, ещё не подтверждённое
  нативным запуском. Остальные промежуточные версии имеют свои ограничения;
  актуальные статусы — в [базе знаний](../engineering-knowledge/topics/evidence.md).

Состав: 14 папок версий V16_9–V16_22, 15 ZIP-выпусков (включая V16_7),
два паспорта WORKING_VERSION. [PRESERVED_FILES.json](PRESERVED_FILES.json)
фиксирует все234 исходных файла и их SHA256, а также commit до переноса.

Папки [diagnostics](../diagnostics/), [docs/agent-knowledge](../docs/agent-knowledge/)
и [weldment_drilling](../weldment_drilling/) оставлены в корне без изменений.
