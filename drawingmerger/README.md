# Объединение чертежей SOLIDWORKS 2025

**Рекомендуемая версия — V16.25.** Пользователь подтвердил успешную работу и выбрал её для дальнейшего использования после сравнения с V16.26. Код и архив V16.25 сохранены без изменений.

[Скачать V16.25](V16_25/SOLIDWORKS_MERGE_V16_25_FAST_EXPERIMENT_VBA_FORM.zip) · [Установка, запуск и таймер](V16_25/README_RU.md)

- Листы добавляются в выбранный основной чертёж; он сохраняется один раз после полного финального аудита.
- PDF всех листов сохраняется автоматически рядом с основным чертежом. Предыдущий PDF сохраняется в папке запуска перед заменой.
- Время работы и этапов — в `runs/<запуск>/TIMING.tsv` и `merge.log`. TOTAL исключает выбор файлов и ожидание закрытия итогового сообщения.
- Итоговые сообщения: «выполнено успешно» или «ошибка, проверьте журнал».
- Основной чертёж изменяется непосредственно; его резервная копия не создаётся. Повторный запуск повторно добавляет листы. Для сравнения скорости нужны одинаковые свежие копии комплекта.

## Сравнение запусков пользователя

| Версия | TOTAL | Решение |
|---|---:|---|
| V16.25 | 189,328 с | Оставлена пользователем как рекомендуемая |
| [V16.26](V16_26/README_RU.md) | 217,641 с | Эксперимент сохранён для истории; не рекомендуется вместо V16.25 |

V16.26 в этом запуске заняла больше общего времени. PREPARE_MAIN вырос с 2,547 до 30,235 с, тогда как обработка источников суммарно стала немного быстрее. Поэтому эти два запуска не доказывают, что новый алгоритм сам по себе медленнее. По решению пользователя дальнейшее использование — V16.25. Автоматического переключения установленного SWP нет: запускайте сохранённый SWP V16.25 либо создайте его из соответствующего архива. Внутренние отчёты кандидата отражают состояние до пользовательского испытания; актуальный выбор зафиксирован здесь.

## Ручное исправление V16.28

На основе V16.27 добавлен отдельный статус REVIEW_REQUIRED при недостаче размеров в итоговом снимке. Макрос оставляет результат открытым, активирует первый проблемный лист и записывает полный список листов/видов, счётчики и происхождение импортированных объектов в REVIEW_REQUIRED.txt. Автоматические Save3 и PDF пропускаются; прежний PDF не обновляется. Полный аудит не пройден, остальные проверки прерваны — перед ручным сохранением пользователь должен проверить весь результат. При отсутствии недостачи сохраняется прежний строгий аудит. Промежуточные ошибки остаются FAILED. Нативное испытание ещё требуется.
